# dio-skills

Skills pessoais do Claude Code (Diogenes) — ferramentas de uso individual, sem relação com o time BenOps RPA. Para skills de equipe, ver [benops-rpa-skills](https://github.com/Gusto-Dio/benops-rpa-skills).

## Estrutura

Cada skill vive em `skills/<nome>/SKILL.md`. Sem manifesto de plugin — para usar uma skill, copie o `SKILL.md` para `~/.claude/skills/<nome>/SKILL.md` e reinicie a sessão do Claude Code.

## Skills

| Skill | Descrição |
|---|---|
| [meeting-copilot](skills/meeting-copilot/SKILL.md) | Monitora ao vivo a transcrição de uma reunião no Notion e escreve uma interpretação personalizada em português no hub pessoal Dio-lab. |
